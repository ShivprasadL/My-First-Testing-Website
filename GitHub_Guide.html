🚀 Git & GitHub Guide

A complete beginner-friendly guide to push your AutomationWebsite1 project to GitHub. Follow step by step.

💡 Part 1: Core Concepts

What is Git?

Git is a version control system — a tool that tracks every change you make to your code. Think of it like an "undo history" for your entire project, but much more powerful.

What is GitHub?

GitHub is a website that hosts Git repositories online. It lets you back up code in the cloud, collaborate with others, and share your projects.

Key Terms

TermMeaning
Repository (Repo)A project folder tracked by Git
CommitA "save point" — a snapshot of your code at a moment in time
BranchA parallel copy of code to experiment safely
PushUpload your local commits to GitHub (cloud)
PullDownload latest changes from GitHub to your computer
CloneDownload an entire repository from GitHub

  2. You commit (save a snapshot) locally
  3. You push to GitHub (upload to cloud)
  4. Others can pull your code, or you access it from anywhere

⬇️ Part 2: Install Git on Windows

🔴

Git is NOT installed on your system. You must install it before running any commands.

Step 1: Download Git

1

Go to https://git-scm.com/download/win

Download the 64-bit version. Download starts automatically.

Step 2: Install Git

2

Run the downloaded .exe file

Click "Next" through most screens — the defaults are fine for beginners.

On the "Adjusting your PATH" screen, ensure "Git from the command line and also from 3rd-party software" is selected (this is the default).

Step 3: Verify Installation

3

Close and reopen your terminal or VS Code, then run:

PowerShellgit --version

You should see: git version 2.45.x.windows.1

💡

If the command still says "not recognized", restart your computer and try again. The PATH needs to refresh.

⚙️ Part 3: One-Time Git Setup

Tell Git who you are. This info is attached to every commit.

PowerShellgit config --global user.name "Your Name"
git config --global user.email "your-email@example.com"
⚠️

Use the same email you used for your GitHub account. This links your commits to your profile.

🎯 Part 5: Push Your Project to GitHub

Open a terminal in your project folder and run these commands one by one:

Step 1: Initialize Git

PowerShellcd "l:\shiv\Tools\Eclipse\AutomationWebsite1"
git init

This creates a hidden .git folder — your project is now a Git repo.

Step 2: Add all files

PowerShellgit add .

This tells Git to track all files. Your .gitignore will automatically exclude target/, logs/, reports/, screenshots/.

Step 3: Create first commit

PowerShellgit commit -m "Initial commit: Selenium TestNG automation framework"

Step 4: Connect to GitHub

PowerShellgit remote add origin https://github.com/YOUR-USERNAME/AutomationWebsite1.git
⚠️

Replace YOUR-USERNAME with your actual GitHub username!

Step 5: Push!

PowerShellgit branch -M main
git push -u origin main
🔐

First time pushing? GitHub will open a browser window for you to log in and authorize Git.

Go to https://github.com/YOUR-USERNAME/AutomationWebsite1 — you should see your files! 🎉

🔁 Part 7: Daily Workflow

After the initial setup, whenever you make changes:

PowerShell# 1. Check what changed
git status

# 2. Add the changed files
git add .

# 3. Commit with a descriptive message
git commit -m "Added login validation test cases"

# 4. Push to GitHub
git push
